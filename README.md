# ⚡ YouTube Playback Speed for ADHD

> **"유튜브 볼 땐 2배속, 노래 들을 땐 1배속... 매번 바꾸기 귀찮으셨죠?"**

이 확장 프로그램은 **ADHD** 성향을 가진 분들(또는 효율을 중요시하는 분들)을 위해 만들어졌습니다.  
정보성 영상은 빠르게 훑어보고 싶지만, 음악이나 라이브 방송은 본연의 속도로 즐기고 싶은 니즈를 해결합니다.

## 🚀 기능 소개 (Features)

- **자동 속도 조절**:
  - 📺 **일반 영상**: 설정한 속도(기본 2.0x)로 자동 재생
  - 🎵 **음악/뮤직비디오**: 자동으로 감지하여 **1.0x (정배속)** 유지
  - 🔴 **실시간 라이브**: 버퍼링 방지를 위해 **1.0x** 유지
  - 🛑 **토글 기능**: 확장 프로그램을 끄면 즉시 1.0x로 복구

- **똑똑한 감지 로직**:
  - 유튜브 공식 카테고리(Music) 감지
  - '믹스(Mix)' 플레이리스트 생성 여부 확인 (알고리즘 기반)
  - 제목 키워드(Cover, MV, Lyrics 등) 감지
  - SPA(페이지 이동) 완벽 지원

## 🛠️ 설치 방법

1. 이 저장소를 다운로드(`git clone` 또는 ZIP 다운로드)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **'개발자 모드'** 켜기
4. **'압축해제된 확장 프로그램을 로드합니다'** 클릭
5. 다운로드 받은 폴더 선택

## 📝 개발 비하인드

이 프로젝트는 **Cursor AI의 Vibe Coding**을 통해 **단 30분 만에** 기획부터 구현까지 완성되었습니다.  
복잡한 설정 없이 직관적으로 동작하는 도구를 만드는 데 집중했습니다.
